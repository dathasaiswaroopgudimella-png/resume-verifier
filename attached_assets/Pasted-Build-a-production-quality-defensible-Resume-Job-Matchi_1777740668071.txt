📦 SYSTEM ARCHITECTURE (MODULAR)

Modules must be separated:

1. Parser Module
   - Input: PDF or text
   - Output: cleaned text
   - Handle errors (empty, corrupted input)

2. Extraction Module
   - Extract:
     - skills
     - experience (years, phrases)
     - project signals

3. Normalization Module
   - Synonyms mapping
   - Case-insensitive matching
   - Deduplication

4. Implicit Skill Inference
   - Phrase → skill mapping
   - Lower weight than explicit skills

5. Embedding Module
   - Generate embeddings
   - Compute cosine similarity
   - Cache job embeddings

6. Soft Domain Classification
   - Output probability distribution
   - Compute alignment via dot product

7. Scoring Engine

Normalize all scores (0–100):

- semanticScore
- weightedSkillScore
- experienceScore

Base Score:
baseScore =
  0.5 * semanticScore +
  0.3 * weightedSkillScore +
  0.2 * experienceScore

---

🚨 PENALTY SYSTEM (CONTROLLED)

Apply AFTER base score:

- domain mismatch (proportional)
- low core skill match (<50%)
- experience gap

Rules:
- aggregate penalties
- damping:
  if totalPenalty > 40 → totalPenalty *= 0.7
- clamp max penalty = 60

finalScore = clamp(baseScore - totalPenalty, 0–100)

---

🧠 DECISION ENGINE

80–100 → STRONG_FIT  
60–79 → GOOD_FIT  
40–59 → WEAK_FIT  
<40 → REJECT  

Override:
- low confidence → INSUFFICIENT_DATA

---

⚠️ ADVERSARIAL DEFENSE

- Detect keyword repetition
- Apply diminishing returns:
  score *= 1 / log(1 + frequency)

---

🧠 CONTRADICTION DETECTION

Add warnings:

📊 CONFIDENCE SCORE

confidence = 1 - normalized_variance(
